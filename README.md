# Apple Stock Market Analysis Dashboard

## Overview

This project analyzes Apple (AAPL) stock market performance from 2020 to 2026 using Python and Power BI.

## Tools Used

* Python
* Pandas
* Power BI
* VS Code

## Key Performance Indicators (KPIs)

* Highest Stock Price (USD)
* Highest Closing Price (USD)
* Average Trading Volume
* Average Daily Return

## Dashboard Features

* Apple Stock Price Trend Analysis
* Trading Volume Analysis
* Moving Average Comparison (MA50 vs MA200)
* Interactive KPI Dashboard

## Project Workflow

1. Collected Apple stock market data.
2. Cleaned and transformed the dataset using Python.
3. Calculated daily returns and moving averages.
4. Built visualizations and KPIs in Power BI.
5. Designed an interactive dashboard for analysis.
